# bae6-context

Context primitives, each built, installed and deployed on its own:
`data` (PostgreSQL, Databricks SQL and S3 connectors), `embed` (ingestion and pgvector
retrieval with ACL enforcement) and `mcp` (tenant-aware MCP server registry).

Plans: [03-CONTEXT](https://github.com/basics-only/bae6-contracts/blob/main/docs/plans/03-CONTEXT.md),
[04-DATA](https://github.com/basics-only/bae6-contracts/blob/main/docs/plans/04-DATA.md),
[05-EMBED](https://github.com/basics-only/bae6-contracts/blob/main/docs/plans/05-EMBED.md),
[06-MCP](https://github.com/basics-only/bae6-contracts/blob/main/docs/plans/06-MCP.md).
